# Codex Model Router 0.9.8 — Mac Apple Silicon

This release adds optional central metrics sharing from Settings → Data.
Sharing is off by default. Enabling it registers this installation automatically
with router.andreifaur.dev; no account, URL or key needs to be entered.

- Share model, effort, usage and result metrics without message content.
- Separate permissions for prompts and raw OTLP diagnostics remain off unless
  explicitly enabled. Stop sharing and request deletion from the same screen.
- Visible synchronization state, bounded local queue and retry/deduplication.
- The private owner panel is hosted on P510 through Sentinel. Server records have
  no automatic expiry; remote backup/restore integration is not available yet.
- Updated connection status avoids claiming a failed connection when Desktop is
  simply closed. The shared source also includes Windows/Ubuntu update adapters.

## Update and trust

Use Settings → Check now → Update, or the Mac arm64 installer. The signed
`codex-model-router-update.json` authenticates the exact package with the existing
project Ed25519 publisher. Configuration, credentials and metrics live outside
the app and are retained. The updater preserves the previous application.

An active Desktop bridge can block replacement. Finish work and close Desktop
normally before retrying; the updater never terminates its agents. This package
is not Apple Developer ID signed or notarized. Do not disable Gatekeeper.

Only the Mac Apple Silicon package is included. Windows and Ubuntu binaries
await transfer from their owner-tested machines; this release does not claim
native update acceptance on those platforms. See the repository native-validation
ledger for the exact evidence and remaining recovery/session checks.
