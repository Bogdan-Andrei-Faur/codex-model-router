# Codex Model Router 0.9.7 — Mac Apple Silicon

This first downloadable release packages the Mac application, bridge and portable
runtime. No Git checkout, Python installation or local compilation is needed.

## Included

- Native macOS installer for Apple Silicon (arm64).
- Settings → Check now → Update, with signed download verification, automatic
  monitor replacement/relaunch and recovery to the previous app on startup failure.
- Guarded import of an existing local installation, retaining configuration,
  characters, history and credential references.
- Corrected companion laptops, unobstructed appearance previews and a cleaner
  compact view without the context bar beneath each character.

The update flow does not terminate Codex/ChatGPT or its agents. If an active
bridge prevents replacement, finish the work and follow the message in Settings.

## Download and trust

Use `codex-model-router-0.9.7-macos-arm64.pkg`. The accompanying
`codex-model-router-update.json` authenticates its exact bytes with the project's
Ed25519 key; `SHA256SUMS` provides a separate file checksum.

The app has ad-hoc code integrity signing. It is **not Apple Developer ID signed
or notarized**; a first download may require macOS approval. This release does not
claim clean-machine or downloaded-quarantine Gatekeeper acceptance. Do not disable
Gatekeeper globally. See [the Mac guide](../MACOS-PILOT.md) for installation and
[the license](../../LICENSE) for personal, noncommercial use terms.

Only the Mac arm64 installer is included. Intel Mac, Windows and Ubuntu installers
are not included in this release. Their native acceptance and managed update
adapters remain separate work.

## Validation scope

The exact package passed native runtime/IPC, relocation, notice and code-integrity
checks, graphical Installer, owner import and ordinary Desktop activation on the
owner's Mac. Local isolated Settings tests cover cancellation, automatic relaunch,
rollback and interrupted-helper replay. Actual login/power-loss recovery and
physical acceptance on other machines remain open.

The real public GitHub Settings update result is recorded separately after
publication, without presenting the earlier local transport fixtures as proof.
